| PTW-081 | Attach: screen garbled until the terminal app is resized once | Fix stale/undersized terminal geometry on attach | a user reported the screen looking garbled right after attaching from a terminal bigger than the session's last size, needing one manual OS-level resize of the terminal application to fix it. Diagnosis: `attach()` sends HELLO with the size from `term_size()` queried before entering raw mode; some consoles (Windows in particular) only fully settle their reported window geometry once something -- entering VT/raw mode, or a real interactive resize -- makes them recompute it, and on Windows specifically the console's screen buffer can start out narrower/shorter than its visible window, which makes the console host itself wrap/clip output early regardless of what pytermwm sends (a manual resize incidentally reconciles buffer and window size, which is why it "fixes" it).

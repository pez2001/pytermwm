# Command reference

Generated by `scripts/gen_reference.py` (with all bundled plugins loaded). The same list is available as `pytermwm ctl commands`, `GET /api/commands`, the MCP tool `list_commands` and `help commands` inside the WM.

## config

| command | usage | description |
|---|---|---|
| `commands` | `commands` | List all commands |
| `config-get` | `config-get [key]` | Show the active configuration (or one key) |
| `reload` | `reload` | Reload the YAML configuration now |
| `source` | `source <file>` | Run commands from a file (one per line, # comments) |

## debug

| command | usage | description |
|---|---|---|
| `debug` | `debug [console\|events\|state]` | Open the debugger/console window |
| `eval` | `eval <python expression>` | Evaluate a python expression with `wm` in scope (needs allow_eval: true) |

## desktop

| command | usage | description |
|---|---|---|
| `close-desktop` | `close-desktop [n]` | Close a desktop and all its windows |
| `desktop` | `desktop <n\|name\|next\|prev\|last\|new [name]>` | Switch desktop (alias: ws) |
| `list-desktops` | `list-desktops` | List desktops (alias: desktops) |
| `new-desktop` | `new-desktop [name]` | Create and switch to a new desktop |
| `rename-desktop` | `rename-desktop <name>` | Rename the current desktop |
| `send-to-desktop` | `send-to-desktop <n\|name> [window]` | Move a window to another desktop |

## io

| command | usage | description |
|---|---|---|
| `pipe` | `pipe <src window> <dst window> [--mute]` | Connect the output of one window to the input of another |
| `route` | `route <window> <out\|err> <window:ID\|stdin:ID\|file:PATH\|none\|reset> [--mute] [--replace]` | Re-route a window's stdout/stderr to another window's display or stdin, or a file, on the fly |
| `routes` | `routes` | Show active routes |

## layout

| command | usage | description |
|---|---|---|
| `balance` | `balance` | Equalize sizes in the current layout |
| `gap` | `gap <n>` | Gap between tiled windows |
| `layout` | `layout <tile\|master\|spiral\|columns\|rows\|monocle\|centered\|grid\|table\|float\|next\|prev\|balance>` | Change the layout engine of the current desktop |
| `layout-set` | `layout-set <master_ratio\|master_count\|grid_cols\|gap\|cols\|rows\|cells> <value>` | Set a parameter of the current layout (cols/rows/cells take JSON) |
| `master-count` | `master-count <n>` | Number of master windows |
| `master-ratio` | `master-ratio <0.1-0.9>` | Size of the master area |
| `resize` | `resize left\|right\|up\|down [cells]` | Resize the focused window |
| `rotate` | `rotate` | Flip the split direction around the focused window (tile layout) |

## session

|---|---|---|

| `quit` | `quit [-f]` | Close everything and end the session (alias: exit) |
| `record` | `record [-t WINDOW] [-i] [-f] [FILE]` | Record a window to an asciicast (.cast) file; -i also records what is typed (passwords too!) |
| `record-mark` | `record-mark [-t WINDOW] [LABEL]` | Add a marker to the recording of a window |
| `record-screen` | `record-screen [-f] [FILE.cast]` | Record the whole screen (all windows, borders, status line) to an asciicast v2 file |
| `record-screen-stop` | `record-screen-stop` | Stop the screen recording |
| `record-stop` | `record-stop [-t WINDOW]` | Stop recording a window |
| `screenshot` | `screenshot [-f] [FILE.svg\|.ans\|.txt]` | Save the whole screen as an SVG picture, ANSI art or plain text (default: an .svg in the state directory) |
| `session-info` | `session-info` | Session information |
| `session-save` | `session-save [file]` | Save the layout/session to disk |
| `up` | `up [--fresh] [FILE]` | Build the desktops and windows described by a project file (.pytermwm.yaml) |
| `web-info` | `web-info` | Show the URL (with access token) of the web interface |

## window

| command | usage | description |
|---|---|---|
| `capture` | `capture [-t window] [-H]` | Return the text content of a window (-H includes history) |
| `clear-history` | `clear-history [window]` | Drop the scrollback of a window |
| `clipboard` | `clipboard [show\|set TEXT...\|list]` | Show or set the paste buffer |
| `close-window` | `close-window [window]` | Close a window (alias: close, kill-window) |
| `copy-mode` | `copy-mode` | Keyboard selection: move with hjkl/arrows, v selects, y copies, Esc cancels |
| `copy-selection` | `copy-selection` | Copy the current mouse selection (when selection.copy_on_release is off) (alias: copy) |
| `copy-view` | `copy-view` | Show only the focused window's text with the mouse off, so the terminal's own selection (PuTTY: drag to copy) gets clean text; any other key returns |
| `cp437` | `cp437 [on\|off\|toggle] [window]` | Toggle on-the-fly CP437 -> UTF-8 conversion |
| `dock` | `dock left\|right\|top\|bottom\|off [size]` | Dock the focused window to a screen edge |
| `float` | `float [on\|off\|toggle] [window]` | Make a window floating / tiled |
| `float-move` | `float-move dx dy` | Move the focused floating window (alias: fmove) |
| `float-rect` | `float-rect x y w h [window]` | Set the rectangle of a floating window |
| `float-resize` | `float-resize dw dh` | Resize the focused floating window (alias: fresize) |
| `focus` | `focus next\|prev\|last\|left\|right\|up\|down\|<window>` | Move focus |
| `list-windows` | `list-windows` | List all windows (alias: ls, windows) |
| `move` | `move left\|right\|up\|down` | Swap the focused window with its neighbour |
| `name` | `name <name> [window]` | Give a window a unique name usable in commands |
| `new-window` | `new-window [-n name] [-t title] [-d desktop] [-c cwd] [-k kind] [-p file] [--pipe] [--float] [--split h\|v] [--keep\|--close] [--no-focus] [-- command...]` | Create a window (default: your shell) (alias: new, nw) |
| `paste` | `paste [text...]` | Paste the paste buffer (or the given text) into the focused window (alias: paste-buffer) |
| `rename` | `rename <title...>` | Set the title of the focused window |
| `replay` | `replay FILE [--speed N] [--idle SECONDS] [--loop] [--float]` | Play an asciicast (.cast) file in a window (keys: Space pause, +/- speed, r restart, arrows skip) |
| `respawn` | `respawn [window]` | Restart the process of a window |
| `scroll` | `scroll up\|down\|page-up\|page-down\|top\|bottom\|left\|right\|<n>` | Scroll the focused window's history |
| `select-all` | `select-all [window]` | Select everything in a window, including its scrollback |
| `send-keys` | `send-keys [-t window] key\|text...` | Send key names (Enter, C-c, Up, ...) or literal text to a window (alias: send) |
| `send-text` | `send-text [-t window] [-n] text...` | Type text into a window (-n adds Enter) |
| `split` | `split h\|v [-- command...]` | Split the focused window (h = side by side, v = stacked) |
| `swap` | `swap <window> <window>` | Swap two windows in the current desktop |
| `vsize` | `vsize <COLSxROWS\|auto> [window]` | Set the virtual size of a window (auto = follow the window) |
| `window-info` | `window-info [window]` | Detailed info about a window (JSON) |
| `window-set` | `window-set <option> <value> [window]` | Change a window option (border, scrollbar, overflow, cp437, history, on_exit, ...) (alias: wset) |
| `zoom` | `zoom [on\|off\|toggle]` | Fullscreen the focused window (alias: fullscreen) |

# MCP tools

Generated by `scripts/gen_reference.py`.

| tool | arguments | description |
|---|---|---|
| `run_command` | **line** | Run a pytermwm command line (e.g. 'layout grid', 'new-window -- htop', 'zoom'). Several commands can be separated with ';'. Use list_commands to discover commands. |
| `list_commands` | - | List every pytermwm command with usage and help. |
| `get_state` | - | Full state: desktops, layouts, windows, focus, theme. |
| `list_windows` | - | List windows with id, title, kind, size and status. |
| `new_window` | **spec** | Open a window. spec keys: cmd (string or list), title, name, kind (term, pipe, file, text, log, viewer, chart, status, dirwatch, help), path (follow a file), desktop, floating, split ('h'/'v'), keep (keep after exit), cwd, env. |
| `close_window` | **window** | Close a window (kills its process). |
| `focus_window` | **window** | Focus a window. |
| `send_keys` | window, text, enter, keys | Type into a window. Use 'text' for literal text (set enter=true to press Enter) or 'keys' for named keys (Enter, C-c, Up, Tab, M-x, F5, ...). |
| `capture_window` | window, history, lines | Read the text currently shown by a window (set history=true for scrollback, lines=N for the last N lines). |
| `wait_for_output` | window, **pattern**, timeout | Wait until a regex appears in a window's text (polls); returns the matching text or times out. |
| `screenshot` | - | The whole rendered screen (all windows, borders, status line) as plain text. |
| `set_status` | **key**, **value**, style | Set a status line item (shown in the status line). |
| `get_logs` | n, level, pattern | Recent log lines of the session. |
| `get_config` | - | The YAML configuration text and the active settings. |
| `set_config` | **text** | Validate and apply a new YAML configuration (saved to the config file when one is in use). |
| `list_rules` | - | Automation rules and scripts with their status. |
| `fire_rule` | **name** | Trigger an automation rule manually. |
| `list_plugins` | - | Loaded and available plugins. |
| `write_script` | **name**, **text** | Save and load a python script (in the scripts directory next to the configuration). |
| `get_selection` | - | The text the user currently has selected (mouse or copy mode) and the paste buffer (what was last copied). |
| `get_help` | topic | A help topic (index, keys, commands, layouts, windows, prompt, themes, config, sessions, automation). |

Bold arguments are required.
